什么是马耳他现成加密货币牌照？

马耳他现成加密货币牌照是指一家已完成注册成立，并已获得（或正处于获取的高级阶段）MFSA 颁发的 Class 3 VFA 牌照的公司。该公司通常是一家无过往交易活动的空壳公司，牌照要么已经签发，要么申请已进展到后期阶段，使新所有者能够接管并比从零开始更快地启动运营。

这与“壳”牌照不同；该公司仍须满足所有持续的合规要求。买方收购整个实体，包括其牌照，然后在获得 MFSA 批准后更新受益所有权和管理层。关键优势在于时间：全新申请可能需要 12-18 个月，而现成牌照可在 3-6 个月内完成转让。然而，买方必须通过与新申请人相同的适当人选测试。MFSA 将审查新所有者、董事和 MLRO。现成实体应拥有干净的合规记录，无任何过往罚款或执法行动。Consulting24 可通过全面的尽职调查流程帮助您核实这一点。

谁需要马耳他现成加密货币牌照？

  • 交易所：运营虚拟资产交易平台，包括现货和保证金交易。
  • 钱包提供商：为零售和机构客户提供托管或非托管钱包服务。
  • 资产管理公司：处理加密货币投资基金或为合格投资者提供投资组合管理。
  • DeFi 协议：需要受监管实体以符合 MiCA 和当地法律。
  • 企业：需要快速行动以在竞争对手之前抓住市场机遇，例如发行新代币或拓展欧盟市场。

如果您是希望依据 MiCA 服务欧盟客户的初创企业或成熟公司，现成牌照可免去漫长等待。然而，对现有实体进行尽职调查至关重要。Consulting24 可帮助您评估目标公司的合规历史和监管状况。我们还建议评估现有业务模式是否与您计划的活动相符，因为某些牌照可能存在限制。

牌照类型与监管机构

相关牌照为《虚拟金融资产法》（马耳他法律第 590 章）下的 Class 3 VFA 牌照。监管机构为马耳他金融服务管理局（MFSA）。截至 2026 年，马耳他已将 MiCA 转化为国内法，因此该牌照也符合 CASP（加密资产服务提供商）注册资格，可用于通行。

Class 3 牌照最为全面，涵盖所有 VFA 服务，包括运营交易平台、执行订单和投资组合管理。较低级别（Class 1 和 Class 2）也存在，但在现成牌照供应中较少见。Class 1 仅涵盖咨询服务，Class 2 涵盖托管和转移服务。Class 3 是唯一允许交易所运营的级别。MFSA 以严格监管著称，因此请预期对您的商业计划、AML 政策和关键人员进行全面审查。

资本要求

根据 MiCA，CASP 的最低资本要求取决于所提供的服务。对于全范围 Class 3 VFA 牌照（涵盖所有服务），资本要求为 EUR 150,000。这是 MiCA 下的最高档（第 67 条）。如果牌照仅涵盖某些服务，如托管或交易所但不含自营交易，则要求可能为 EUR 125,000 或 EUR 50,000。现成实体应已具备该资本，或者您必须在收购后注入。资本必须以流动资产形式持有，不得用于运营支出。它作为抵御破产的缓冲。Consulting24 可就资本注入的结构设计提供建议，以满足 MFSA 要求。

税务处理

马耳他提供极具竞争力的企业税制。标准企业税率为 35%，但通过完全归集制度和退税，贸易公司的实际税率可低至 5%。加密货币交易被视为普通营业收入。加密货币对加密货币的交易不征收增值税，但法币兑换可能需要缴纳增值税。加密货币的资本利得通常需纳税，但长期持有可能适用特定豁免。马耳他还对子公司股息实行参股豁免。Consulting24 建议聘请当地税务顾问进行架构设计。税收优惠使马耳他对控股公司和贸易公司极具吸引力。

常见问题

什么是马耳他现成加密牌照？

它是一家已预先注册成立的公司，已持有（或即将持有）MFSA颁发的Class 3 VFA牌照。您收购整个实体（包括牌照），从而能够比新申请更快地开始运营。该公司通常是没有任何先前交易活动的空壳公司。

转让现成牌照需要多长时间？

通常为3至6个月，取决于控制权变更的复杂程度和MFSA的审查速度。这比全新申请（可能需要12-18个月）快得多。时间表还取决于您提供所需文件的速度。

马耳他加密牌照的最低资本要求是多少？

根据MiCA，全范围CASP的资本要求为EUR 150,000。对于有限服务，可能为EUR 125,000或EUR 50,000。现成实体应已满足此要求。您必须始终维持该资本。

我能否使用马耳他牌照为其他欧盟国家的客户提供服务？

可以。马耳他已转化MiCA，因此Class 3 VFA牌照符合CASP注册资格。您可以通过通知MFSA在欧盟/欧洲经济区范围内通行证化服务。您必须遵守当地营销规则，并可能需要向東道国监管机构注册。

马耳他加密利润适用什么税率？

标准企业所得税税率为35%，但通过退税，贸易公司的实际税率可低至5%。加密收益按普通收入处理。加密对加密交易不征收增值税。具体事宜请咨询当地税务顾问。

我需要在马耳他设立实体办公室吗？

是的，MFSA 要求在马耳他有注册办公室和实质经营。这可以是服务式办公室或共享办公空间。您还需要一名本地董事或 MLRO。办公室不能只是一个邮箱地址。

如果我是非欧盟居民，可以购买现成的牌照吗？

可以，非欧盟居民可以收购马耳他牌照。但是，受益所有人和董事必须通过适当人选测试。您可能需要任命一名具有加密货币经验的本地董事。MFSA 将审查您的背景。

持续的合规成本有哪些？

年度合规成本通常在 EUR 20,000 至 40,000 之间。这包括 MLRO 费用、审计、AML 软件和法律更新。具体金额取决于您运营的复杂程度和交易量。

我可以将马耳他牌照用于 DeFi 业务吗？

可以，但 MFSA 期望 DeFi 协议由受监管实体运营。您必须对智能合约拥有控制权，并遵守 AML/KYC 要求。某些 DeFi 模式可能不符合监管框架，因此请寻求法律建议。
