什么是菲律宾加密NFT市场牌照？

菲律宾加密NFT市场牌照是菲律宾中央银行（BSP）根据虚拟资产服务提供商（VASP）框架颁发的监管批准。任何促进虚拟资产（包括非同质化代币NFT）交换、转移或存储的平台都需要获得该牌照。该牌照确保市场在运营中具备充分的治理、反洗钱（AML）控制和消费者保护措施。

截至2026年，BSP已更新其指导方针，专门针对NFT市场，认可其在数字经济中的独特作用。该牌照并非一刀切；它根据平台的活动量身定制，例如一级销售、二级交易或NFT托管。例如，仅托管数字艺术品一级销售的市场，其合规负担可能比提供托管钱包和二级交易的市场更简单。BSP还要求VASP对超过PHP 500,000的虚拟资产转移实施旅行规则，这涉及收集和共享发送方和接收方信息。

Consulting24与菲律宾法律合作伙伴进行咨询和协调，使您的商业模式与BSP的期望保持一致。我们帮助您界定服务范围并准备必要文件，包括详细的商业计划和AML手册。

谁需要此牌照？

任何在菲律宾运营连接NFT买卖双方的在线平台的实体都必须获得VASP牌照。这包括：

  • 数字艺术、音乐和收藏品的NFT市场
  • 交易游戏内NFT的游戏平台
  • 房地产或大宗商品等代币化现实世界资产的市场
  • 提供NFT铸造和二级交易的平台
  • 任何为NFT促进法币兑加密货币或加密货币兑加密货币交易的平台

如果您的平台处理NFT的法币兑加密货币或加密货币兑加密货币交易，则属于BSP监管范围。即使您仅促进点对点交易而不持有客户资金，仍需要获得牌照。BSP已明确，任何将虚拟资产买卖双方聚集在一起的中介机构均为VASP。例如，允许NFT交易的社交媒体平台也需要牌照。Consulting24可以帮助您评估您的商业模式是否触发牌照要求，并据此为您提供指导。我们还可以就您的平台是否有资格获得豁免提供建议，例如您仅提供NFT铸造而不提供任何交易或转移服务。

牌照类型与监管机构

该牌照的正式名称为虚拟资产服务提供商（VASP）注册证书，由菲律宾中央银行（BSP）颁发。BSP是菲律宾的中央银行，也是根据经修订的第9160号共和国法（反洗钱法）负责虚拟资产活动的主要监管机构。VASP注册并非完整的银行牌照，而是针对数字资产服务的特定授权。

截至2026年，BSP要求VASP遵守最新的AML/CFT指导方针，包括虚拟资产转移的旅行规则。监管机构还进行定期现场检查和年度审计。BSP设有专门的虚拟资产部门，负责处理VASP申请和监管。Consulting24与当地合规专家进行咨询和协调，确保您的申请符合BSP标准。我们还监测监管更新，因为BSP可能会发布影响NFT市场的新通告。

资本要求

截至2026年，BSP未规定VASP注册的固定最低资本。然而，申请人必须证明拥有足够的财务资源以支付运营费用和潜在负债。通常，BSP期望标准VASP的最低实缴资本为PHP 1,000万（约EUR 170,000）。对于风险较高的NFT市场，例如提供托管服务的市场，资本可能更高，最高可达PHP 2,000万。

资本必须存放在菲律宾银行账户中，并可自由支配。不得为借入资金，也不得设有任何产权负担。Consulting24 就如何安排资本结构以满足 BSP 的预期提供建议。作为对比，巴拿马收取 EUR 6,000 的统一费用，且无最低资本要求，这使其成为早期项目颇具吸引力的替代方案。同样，在 MiCA 框架下，立陶宛根据服务类型要求 EUR 50,000 至 150,000 的资本，对某些业务而言可能低于菲律宾的要求。

税务处理

在菲律宾经营 NFT marketplace 业务需缴纳 25% 的企业所得税（根据 CREATE 法案，小型企业可适用更低税率：净应税所得低于 PHP 5 百万且总资产低于 PHP 1 亿的公司，税率降至 20%）。此外，如果平台收取费用，相关交易可能需缴纳 12% 的增值税（VAT）。对于 NFT 销售，卖方可能需要根据资产性质缴纳资本利得税或所得税。

国内税务局（BIR）已发布数字资产税务指南，将 NFT 视为无形资产。BIR 要求 VASP 对某些交易代扣税款并进行申报。Consulting24 就如何安排您的 marketplace 结构以优化税务效率提供建议。若寻求税务中性的替代方案，可考虑司法管辖区如巴拿马，其对离岸收入不征收企业所得税。立陶宛也提供 15% 的企业税率，对于较高利润而言可能低于菲律宾的税率。

允许的活动

持有 VASP 牌照，您的 NFT marketplace 可以开展以下活动：

  • 为创作者促成 NFT 的一级销售
  • 运营 NFT 交易的二级市场
  • 提供 NFT 铸造服务
  • 为 NFT 提供托管钱包服务
  • 为 NFT 购买实现法币与加密货币之间以及加密货币与加密货币之间的兑换
  • 为 NFT 交易提供托管服务

未涵盖的活动包括借贷、质押或衍生品，这些需要另行获得证券交易委员会（SEC）的许可。BSP 还禁止交易隐私币或具有匿名功能的资产，如 Monero 或 Zcash。Consulting24 可帮助您界定服务范围以确保合规。如果您计划提供额外服务，我们可以就获取必要的补充牌照提供建议。

分步申请流程

获得菲律宾加密货币 NFT Marketplace 牌照的流程涉及多个阶段。Consulting24 为每一步提供建议并协调：

  1. 申请前咨询：我们评估您的商业模式并制定合规路线图。这包括对您当前运营与 BSP 要求之间的差距分析。
  2. 公司注册：在证券交易委员会（SEC）注册一家菲律宾公司。您需要至少五名发起人、一名常驻董事，以及一名菲律宾籍的公司秘书。
  3. AML 计划制定：起草政策、风险评估和内部控制。这包括客户尽职调查（CDD）、交易监控和可疑交易报告。
  4. 文件提交：向 BSP 提交 VASP 申请，包括商业计划、财务报表、AML 手册和组织结构。
  5. BSP 审查与面谈：BSP 评估申请，并可能对关键人员（如合规官和 CEO）进行面谈。
  6. 批准与注册：获批后，BSP 颁发注册证书。随后您必须在反洗钱委员会（AMLC）注册，并遵守持续报告义务。

在整个流程中，Consulting24 与当地法律和合规合作伙伴保持联络。总时长通常为 4-8 个月，具体取决于您申请的完整程度以及 BSP 的工作量。

银行与支付

在菲律宾开设公司银行账户是获得 VASP 牌照的前提条件。BDO、Metrobank 和 Bank of the Philippine Islands（BPI）等主要银行接受 VASP 申请人，但要求提供 BSP 注册证明或至少申请证明。部分银行还可能要求 PHP 5 百万的最低存款以及业务运营记录。

在支付处理方面，您可以整合 PayMaya 或 GCash 等本地网关以实现法币入金。Stripe 或 PayPal 等国际支付提供商也可能可用，但它们通常对加密货币相关业务设有诸多限制。Consulting24 可以为您引荐了解加密货币领域的银行合作伙伴。若希望更简便的银行开户流程，立陶宛为加密货币公司提供更直接的程序，许多银行愿意为持牌 VASP 开设账户。巴拿马也拥有有利的银行环境，且无资本管制。

菲律宾牌照的优势

在菲律宾获得 VASP 牌照具有多项优势：

  • 监管明确：BSP 提供清晰的框架，减少 NFT marketplace 的法律不确定性。
  • 市场增长：菲律宾数字资产的采用率很高，尤其是在无银行账户人群中。超过 70% 的成年人拥有手机，加密货币使用广泛。
  • 战略位置：可进入东盟地区，并拥有庞大的英语劳动力。菲律宾是外包和技术人才的枢纽。

合规与信任

运营持牌 NFT marketplace 可建立用户和合作伙伴的信任。遵守 BSP 法规包括：

  • AML/CFT 政策，包括客户尽职调查（CDD）和交易监控。对于超过 PHP 500,000 的交易或任何可疑活动，您必须核实用户身份。
  • 对超过 PHP 500,000 的转账遵守 Travel Rule。这要求收集并与交易对手共享发送方和接收方信息。
  • 定期向 BSP 和反洗钱委员会（AMLC）报告。报告包括可疑交易报告（STR）和年度合规报告。
  • 由 BSP 批准的外部审计师进行年度审计。
  • 任命具有相关经验的常驻合规官。

应避免的常见错误

许多申请人因可避免的错误而面临延误。常见错误包括：

  • 提交不完整的文件，例如缺少 AML 政策或财务报表未经菲律宾注册会计师审计。
  • 低估资本要求，未能证明在菲律宾银行账户中持有充足资金。
  • 选择包含被禁止活动的商业模式（例如隐私币、未经 SEC 批准的衍生品）。
  • 没有菲律宾公民或居民担任的本地常驻董事或合规官。
  • 未为 BSP 面谈做好准备，关键人员必须在面谈中展示对 AML 法规的了解。
  • 使用未针对 NFT marketplace 风险量身定制的通用 AML 手册。

菲律宾的 NFT 交易平台有最低资本要求吗？

BSP 未设定固定的最低资本，但要求申请人证明拥有充足的财务资源。通常期望实缴资本达到 PHP 1,000 万（约合 EUR 170,000）。如果提供托管服务，可能需要更高的资本。

我可以在没有牌照的情况下在菲律宾运营 NFT 交易平台吗？

不可以。无 VASP 牌照运营属于违法行为，可能导致罚款、关闭和刑事责任。BSP 积极监控无牌 VASP，并已采取执法行动。在启动之前必须获得牌照。

菲律宾 VASP 牌照下哪些活动被禁止？

被禁止的活动包括交易隐私币（如 Monero、Zcash）、未经 SEC 批准提供借贷或质押服务，以及提供衍生品。BSP 还禁止匿名交易，并要求遵守 Travel Rule。

我需要当地董事或合规官吗？

需要。BSP 要求 VASP 至少有一名常驻董事，须为菲律宾公民或永久居民，并配备一名常驻菲律宾的合规官。这确保了本地问责和监管监督。

菲律宾 NFT 交易平台运营适用哪些税种？

企业所得税为 25%（根据 CREATE 法案，小型企业为 20%）。平台费用适用 12% 的增值税。NFT 销售可能触发卖方的资本利得税或所得税。BIR 对数字资产有具体指引。Consulting24 提供税务优化建议。

对于 NFT 交易平台，巴拿马相比菲律宾有哪些优势？

巴拿马提供 EUR 6,000 的统一收费、无最低资本要求、离岸收入免征企业所得税，以及更快的设立速度（2-3 个月）。非常适合面向全球市场的初创企业。不过，菲律宾提供进入东盟地区的渠道和庞大的本地用户群。

菲律宾 VASP 牌照是否获得国际认可？

该牌照仅适用于菲律宾，不会自动允许在其他国家运营。但它能证明监管合规性，有助于与国际银行和交易所建立合作。如需进入欧盟，可考虑在立陶宛申请 MiCA 牌照。
