什么是哈萨克斯坦加密 NFT 市场牌照？

哈萨克斯坦加密 NFT 市场牌照允许公司运营一个平台，供用户购买、出售和交易非同质化代币（NFT）及其他加密资产。该牌照由阿斯塔纳金融服务管理局（AFSA）根据 AIFC 框架颁发，或由哈萨克斯坦国家银行向 AIFC 以外的实体颁发。AIFC 制度尤其具有吸引力，因为它采用英国普通法体系、提供税收优惠并拥有简化的牌照流程。

该牌照涵盖运营数字资产交易设施、数字资产托管以及提供相关服务等活动。它专为促进 NFT 及其他加密资产点对点交易的平台而设计，包括一级发行和二级市场交易。例如，像 OpenSea 或 Rarible 这样的平台如果设在哈萨克斯坦，就属于该牌照的适用范围。AIFC 规则手册以 IOSCO 和 FATF 的国际标准为基础，为全球投资者提供了熟悉的框架。

谁需要该牌照？

任何计划在哈萨克斯坦运营 NFT 或其他加密资产市场的企业都需要该牌照。这包括：

  • NFT 市场（艺术品、收藏品、游戏物品、房地产代币）
  • 数字资产二级市场平台
  • 提供 NFT 一级发行（铸造服务）的平台
  • 为 NFT 交易提供托管或第三方保管服务的企业
  • 促进 NFT 交易的去中心化自治组织（DAO）

如果您是瞄准中亚市场的加密创始人，或正在寻找成本具有竞争力且监管完善的司法管辖区，该牌照是一个强有力的选择。Consulting24 为申请流程提供建议和协调，确保符合当地法律。我们帮助您确定 AIFC 制度还是国家制度更适合您的商业模式。

牌照类型与监管机构

哈萨克斯坦加密资产服务的主要监管机构是阿斯塔纳国际金融中心（AIFC）内的阿斯塔纳金融服务管理局（AFSA）。AIFC 提供特定的牌照类别：数字资产交易设施（DATF）牌照。该牌照涵盖运营数字资产（包括 NFT）交易平台。AFSA 规则手册将数字资产分为支付代币、功能型代币、资产参照代币和 NFT，每类都有具体要求。

对于在 AIFC 以外运营的实体，哈萨克斯坦国家银行和数字发展部根据《数字资产法》监管另一套注册制度。不过，AIFC 途径更为简化且获得国际认可。Consulting24 根据客户的商业模式，综合考虑目标市场、资产类型和运营复杂度等因素，为客户提供最佳选择建议。

税务处理

AIFC 的主要优势之一是其税收制度。在 AIFC 内获得许可的实体，就其来自 AIFC 受监管活动的收入，可享受为期 50 年的 0% 企业所得税。此外，AIFC 内的数字资产交易不征收增值税。对于 AIFC 以外的实体，适用 20% 的标准企业税率，但数字资产业务可能享有特定豁免。AIFC 还提供向非居民支付的股息和利息免征预提税的优惠。

员工的个人所得税为 10%（统一税率）。与欧洲司法管辖区相比，社会保障缴款相对较低。Consulting24 就业务架构提供建议，以优化税收优惠，包括转让定价和知识产权持有。我们建议咨询当地税务顾问以进行详细规划。

AIFC 牌照是否获得国际认可？
