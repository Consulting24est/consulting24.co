什么是巴哈马加密稳定币牌照？

巴哈马加密稳定币牌照是由巴哈马证券委员会（SCB）根据 DARE 法案颁发的监管授权。它允许公司发行、赎回和管理稳定币——即锚定美元等稳定资产的数字资产。该牌照属于一套全面制度的一部分，该制度还涵盖数字资产交易所、托管机构及其他服务提供商。

巴哈马是最早颁布专门数字资产法律的国家之一，其框架以既严格又利于营商而著称。DARE 法案要求稳定币发行方维持全额储备、接受定期审计，并遵守反洗钱（AML）和反恐怖主义融资（CFT）义务。SCB 对所有持牌实体进行监管，以确保消费者保护和金融稳定。对于稳定币项目而言，该牌照提供了法律确定性，并有助于建立用户和合作伙伴的信任。

与其他司法管辖区相比，巴哈马为稳定币提供了量身定制的制度，不同于某些欧盟成员国——在这些国家，稳定币发行可能属于更广泛的 CASP 规则范畴，且资本门槛更高。Consulting24 可以帮助您将巴哈马与立陶宛或爱沙尼亚等选项进行比较，以找到最佳匹配。

谁需要巴哈马加密稳定币牌照？

该牌照对于任何打算在巴哈马境内或从巴哈马发行稳定币，或向巴哈马居民提供稳定币相关服务的实体而言都至关重要。典型申请人包括：

  • 推出用于支付或汇款的美元锚定稳定币的金融科技初创企业
  • 拓展数字货币业务、寻求受监管法币入金通道的成熟支付公司
  • 需要为其生态系统提供合规稳定币的去中心化金融（DeFi）项目
  • 为内部结算或供应链金融发行稳定币的企业财资部门
  • 将现实世界资产（如黄金、房地产）代币化为稳定币的资产管理机构

如果您的商业模式涉及创建稳定币、管理其锚定机制，或促进其在支付或交易中的使用，巴哈马提供了可信的监管归属地。例如，一家旨在推出用于跨境支付的美元支持稳定币的金融科技公司，将受益于巴哈马清晰的规则和税收中性。Consulting24 就该牌照是否适合客户的具体商业模式提供建议，并可协调申请流程。

牌照类型与监管机构

巴哈马加密稳定币牌照的监管机构是巴哈马证券委员会（SCB）。该牌照属于《2020年数字资产与注册交易所（DARE）法案》范畴，该法案将稳定币发行归类为“数字资产业务”。SCB 是国际证券委员会组织（IOSCO）的成员，并遵循国际标准。

DARE 法案下有两个主要牌照类别：

  • I 类（注册）：适用于向有限数量客户提供数字资产服务的企业（例如，为企业集团提供的私有稳定币）。资本要求较低，合规更简单。适合试点项目或内部使用。
  • II 类（完整牌照）：适用于向公众提供服务的企业，包括向零售用户发行稳定币。要求更高资本和更广泛的监管义务。这是大多数面向广泛用户群的稳定币发行方的标准。

大多数稳定币发行方将需要 II 类牌照。SCB 还为规模有限的创新项目颁发“沙盒”牌照，但完整的稳定币发行通常不在沙盒参数范围内。如需与其他监管框架进行比较，请参阅我们的与立陶宛的比较。

资本要求

DARE 法案根据牌照类别和服务性质规定了最低资本要求。对于 II 类牌照（公开稳定币发行），最低资本通常为$500,000。该金额必须作为流动资产维持，并可能根据流通中的稳定币数量而增加。例如，如果您计划发行 $10 million 的稳定币，SCB 可能要求超出最低限额的额外资本。

对于 Class I（注册类）牌照，最低资本要求较低，通常在 100,000 美元左右。然而，大多数面向广泛用户群体的稳定币项目将需要达到 Class II 门槛。资本必须存放在巴哈马银行账户中，或投资于政府债券等经批准的流动性工具。SCB 还可能要求提供保证债券或保险以覆盖某些风险。

相比之下，在欧盟 MiCA 框架下，稳定币发行人面临的资本要求为 350,000 欧元或更高，具体取决于发行规模。Consulting24 可以帮助您高效地构建资本结构，以满足 SCB 的要求。

税务处理

巴哈马为数字资产业务提供了极为优惠的税收制度。要点如下：

  • 无企业所得税
  • 无资本利得税
  • 无预提税
  • 数字资产服务免征增值税（VAT）
  • 数字资产交易免征印花税
  • 无遗产税或赠与税

然而，企业必须向 SCB 缴纳年度牌照费，如果拥有实体存在，还必须遵守经济实质要求。稳定币发行人通常无需缴纳利润税，这使巴哈马成为极具吸引力的运营基地。例如，一家年费收入为 100 万美元的稳定币发行人将缴纳零企业所得税，而在许多欧盟司法管辖区则需缴纳 15-25%。

Consulting24 可以在咨询期间提供有关税务架构的更多细节，包括如何利用巴哈马的税收协定（尽管有限）以及避免双重征税。

牌照允许的活动

巴哈马加密稳定币牌照允许以下活动：

  • 发行稳定币（法币抵押型、商品抵押型或算法型，须经 SCB 批准）
  • 按面值将稳定币赎回为法币或其他资产
  • 管理支持稳定币的储备资产，包括托管和投资
  • 为稳定币及相关数字资产提供托管服务
  • 促进稳定币转账和支付，包括跨境交易
  • 向巴哈马及国际客户营销和分销稳定币（须遵守当地法律）

该牌照并不自动允许运营数字资产交易所或提供投资建议；这些需要根据 DARE Act 获得单独授权。稳定币发行人还必须遵守 SCB 的储备要求，包括由合格审计师进行定期鉴证。例如，稳定币发行人必须持有等于未偿付稳定币 100% 的现金或现金等价物储备，并提供月度鉴证。

分步申请流程

合规与持续义务

获得牌照后，稳定币发行人必须遵守持续的合规要求：

  • 以流动资产维持全额储备（法币抵押型稳定币为 1:1 支持），并由独立审计师进行月度鉴证
  • 向 SCB 提交月度或季度储备鉴证，包括储备构成的明细
  • 向 SCB 提交年度报告，包括经审计的财务报表和合规报告
  • 对员工进行定期 AML/CFT 培训，并实施交易监控系统
  • 在规定时限内向金融情报单位（FIU）报告可疑交易
  • 将业务运营、所有权或管理层的任何重大变更通知 SCB

应避免的常见错误

申请人经常犯下延误或危及牌照的错误。请避免以下陷阱：

  • 商业计划不充分：SCB 期望获得涵盖运营、风险管理和退出策略的详细计划。通用模板式的计划会被拒绝。请包含稳定币发行量和储备管理的具体预测。
  • 资本不足：请确保在申请前已备妥所需的最低流动资产资本。SCB 可能要求提供来自信誉良好银行的资金证明。
  • AML/CFT 政策薄弱：SCB 会严格审查合规框架；通用政策将被拒绝。请针对稳定币特有的风险（如匿名性和跨境转账）量身定制您的政策。
  • 忽视经济实质：巴哈马要求持牌实体具备实体存在，包括办公室和本地员工。仅依赖注册代理是不够的。
  • 低估时间周期：整个流程可能需要 4-8 个月；请据此做好规划。仓促提交申请往往会导致错误。
  • 未聘请当地律师：SCB 期望申请人携手巴哈马法律顾问开展工作。Consulting24 可协调当地合作伙伴。

常见问题

巴哈马稳定币牌照的最低资本是多少？

对于 Class II（完整）牌照，最低资本为 $500,000。该资金必须以现金或政府债券等流动资产形式持有。对于 Class I（注册）牌照，最低资本约为 $100,000。SCB 可能根据稳定币发行量要求追加资本。

获得巴哈马加密稳定币牌照需要多长时间？

从提交申请到牌照签发，典型时间周期为 4-8 个月。这包括公司注册、文件准备、SCB 审查和尽职调查。Consulting24 可通过确保所有文件完整且合规来帮助简化流程。

巴哈马稳定币牌照有哪些税务优惠？

巴哈马对数字资产服务不征收企业所得税、资本利得税、预提税、增值税或印花税。这使得其对稳定币发行方极具吸引力，因为与企业所得税税率为 15-25% 的司法管辖区相比，他们可以保留更多收入。

我可以在巴哈马牌照下发行算法稳定币吗？

可以，但算法稳定币因其较高风险而受到 SCB 的额外审查。SCB 要求详细说明算法、风险管理程序以及脱锚事件的应急计划。批准并非必然，且可能需要进行修改。

我需要在巴哈马设立实体办公室吗？

是的，SCB 期望持牌实体在巴哈马具备实体存在，包括办公室和本地员工。这是经济实质要求的一部分。Consulting24 可协助设立合规的办公场所。

获得牌照后有哪些持续合规要求？

持续要求包括维持全额储备并提交月度证明、提交年度报告、开展 AML/CFT 培训以及报告可疑交易。SCB 还可能进行定期检查。

我可以使用巴哈马牌照为欧盟客户提供服务吗？

不可以，巴哈马牌照不提供进入欧盟的通行权。要为欧盟客户提供服务，您需要在欧盟成员国（如立陶宛或爱沙尼亚）根据 MiCA 另行获得牌照。Consulting24 可就多司法管辖区策略提供建议。

在稳定币牌照方面，巴哈马与巴拿马相比如何？

巴拿马提供更快、更便宜的选择（EUR 6,000 统一收费，2-3 个月），且无资本要求，但其监管框架并非专为稳定币设计。巴哈马提供专门的稳定币制度，资本要求更高、时间周期更长，但监管清晰度更高。

如果我未能维持所需储备会怎样？

未能维持全额储备可能导致罚款、暂停或吊销牌照。SCB 还可能要求立即赎回未偿付的稳定币。建立强有力的储备管理程序至关重要。

我可以在获得完整牌照之前先申请沙盒牌照吗？

可以，SCB 为规模有限的创新项目提供监管沙盒。然而，由于涉及系统性风险，稳定币发行通常需要完整牌照。沙盒可能适合在扩大规模之前测试原型。
