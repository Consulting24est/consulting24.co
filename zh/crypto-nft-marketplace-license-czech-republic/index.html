什么是捷克共和国加密 NFT 市场牌照？

捷克共和国加密 NFT 市场牌照是运营平台所需的授权，用户可在该平台上使用加密货币购买、出售和交易非同质化代币（NFT）。根据 MiCA，该活动属于提供加密资产服务的范畴，具体而言是运营加密资产交易平台。该牌照由捷克国家银行（CNB）颁发，并与欧盟范围内的监管框架保持一致，确保高标准的投资者保护和市场诚信。

该牌照涵盖运营 NFT 市场的活动，即促进加密资产（包括 NFT）与法定货币或其他加密资产之间的兑换。它还包括代表客户托管和管理加密资产，这对于在交易期间以托管方式持有 NFT 的市场而言十分常见。截至 2026 年，捷克共和国已将 MiCA 全面转化为国内法，以更全面的牌照制度取代了此前的注册制度。

谁需要捷克共和国加密 NFT 市场牌照？

任何运营 NFT 与法定货币或其他加密资产交易平台的法律实体都需要牌照。这包括：

  • 接受加密货币支付并促进点对点交易的 NFT 市场。
  • 提供 NFT 一级销售（铸造和销售）且平台作为中介的平台。
  • 为 NFT 提供托管服务的企业，例如为用户持有私钥。
  • 提供 NFT 质押或收益生成的市场。

如果您的平台仅提供信息或上架服务，而不处理任何加密资产或法定货币，则可能不需要牌照。然而，大多数处理交易的 NFT 市场都将属于 MiCA 的适用范围并需要授权。Consulting24 建议客户评估其具体业务模式，以确定牌照义务。

牌照类型与监管机构

相关监管机构是捷克国家银行（CNB），它作为 MiCA 下加密资产服务提供商的主管机关。牌照类型为CASP（加密资产服务提供商）牌照，取代了 MiCA 之前实施的注册制度。CNB 针对特定服务类别颁发牌照，包括运营交易平台（涵盖 NFT 市场）、托管和管理以及兑换服务。

CNB 以其全面但公正的评估流程而闻名。申请人必须证明具备强有力的 AML/CFT 管控、适当的治理和充足的资本。CNB 还要求该实体在捷克共和国拥有实际存在，包括注册办公地址以及至少一名居住在該国的董事或经理。Consulting24 与当地法律合作伙伴协调，确保满足所有要求。

捷克加密牌照的资本要求

根据 MiCA，CASP 牌照的最低资本要求取决于所提供服务的类型。对于运营交易平台（NFT 市场），资本要求为 EUR 150,000。这是 MiCA 下较高的档位之一，反映了运营处理多种资产并促进交易的平台所涉及的风险。

该资本必须以流动资产形式持有并始终保持。它可以采用现金、银行担保或高流动性证券的形式。如果业务模式涉及更高风险，例如提供保证金交易或复杂金融产品，CNB 可能要求额外资本。Consulting24 帮助客户高效地构建其资本结构，以满足监管要求。

捷克共和国加密 NFT 市场的税务处理

捷克共和国对加密企业实行优惠的税收制度。截至 2026 年，企业所得税为统一19% 的利润率。加密资产的资本利得被视为收入，适用相同税率。加密对加密交易不适用增值税，但市场收取的费用（例如上架费、交易费）适用 21% 的标准增值税。

对于个人而言，如果持有加密货币超过三年，且每年来自加密货币的总收入不超过 100,000 捷克克朗（约 4,000 欧元），则加密货币收益免税。然而，对于企业而言，所有收益均需纳税。捷克共和国还与许多国家签订了双重征税协定，这可以减少股息和利息的预扣税。Consulting24 建议咨询当地税务顾问以了解确切的义务。

捷克加密货币 NFT 市场牌照允许的活动

捷克共和国的 CASP 牌照允许开展以下与 NFT 和加密资产相关的活动：

  • 运营加密资产（包括 NFT）交易平台。
  • 将加密资产兑换为法定货币或其他加密资产。
  • 代表客户托管和管理加密资产。
  • 代表客户执行订单。
  • 配售加密资产（例如首次 NFT 发行）。
  • 接收和传递加密资产订单。

未经额外牌照不允许开展的活动包括提供银行服务（例如借出法定货币）、发行证券（除非根据招股说明书）或提供衍生品。该牌照专门针对加密资产，不涵盖传统金融工具。Consulting24 建议客户明确界定其服务范围，以避免违反监管规定。

获取捷克加密货币 NFT 市场牌照的分步流程

申请流程包括几个阶段：

  1. 申请前准备：确定商业模式，准备 AML/KYC 政策，并起草内部程序。聘请当地法律顾问。
  2. 公司注册：设立一家捷克有限责任公司（s.r.o.），需有注册办公地址和至少一名居住在捷克共和国的董事。
  3. 资本存入：将最低资本 150,000 欧元存入捷克银行账户，并取得银行的确认。
  4. 提交申请：向 CNB 提交申请，包括商业计划、AML 政策、组织架构和财务预测。
  5. CNB 审查：CNB 审查申请，可能需要 3-6 个月。他们可能会要求提供额外信息或澄清。
  6. 牌照颁发：如果获批，CNB 将颁发 CASP 牌照。此后，公司必须遵守持续的报告和审计要求。

持续合规要求有哪些？
