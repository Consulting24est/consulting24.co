什么是适用于 NFT 市场的直布罗陀加密牌照？

直布罗陀加密牌照是 GFSC 根据《金融服务（分布式账本技术提供商）条例》颁发的监管授权。它专为使用分布式账本技术（DLT）存储或传输他人价值的企业而设，包括加密交易所和 NFT 市场。任何在直布罗陀境内或从直布罗陀提供 DLT 服务的企业都必须持有该牌照。

对于 NFT 市场而言，这意味着您的平台必须遵守反洗钱（AML）、反恐怖主义融资（CTF）和消费者保护规则。该制度以原则为基础，聚焦于九项核心原则，如诚实、诚信和充足的财务资源。与某些将 NFT 仅视为收藏品的司法管辖区不同，直布罗陀将其 DLT 框架适用于任何代表价值的代币，包括非同质化代币，前提是平台为其交易或托管提供便利。

Consulting24 就本牌照的适用性为客户提供咨询，并将其与爱沙尼亚加密牌照或立陶宛 CASP 制度等其他选择进行比较。我们不在直布罗陀直接提交申请，而是与当地法律合作伙伴协调，以确保申请顺利进行。

谁需要为 NFT 市场申请直布罗陀加密牌照？

任何运营 NFT 市场并从直布罗陀提供以下任一服务的企业都需要牌照：运营 NFT 交易平台、为 NFT 提供托管或钱包服务，或为 NFT 与法币或其他加密资产之间的兑换提供便利。这包括允许用户铸造、上架、购买、出售或拍卖 NFT 的平台。

如果您的企业在直布罗陀注册成立，即使客户遍布全球，您同样需要牌照。GFSC 采取属地原则：如果您的 DLT 活动在直布罗陀管理或指挥，则该牌照适用。这既涵盖初创企业，也涵盖寻求迁入或扩展至受监管环境的成熟平台。

Consulting24 帮助您评估您的商业模式是否触发牌照要求。我们还将直布罗陀路径与其他司法管辖区进行比较，例如巴拿马——其提供更简单的公司架构且无需专门加密牌照，或立陶宛——其拥有完全符合 MiCA 的制度。

牌照类型与监管机构

直布罗陀加密牌照的正式名称为“分布式账本技术提供商牌照”。它由直布罗陀金融服务委员会（GFSC）颁发，该委员会是直布罗陀金融服务的统一监管机构。GFSC 自 2018 年起对 DLT 提供商进行监管，是全球最早的先行者之一。

DLT 牌照只有一种类型，涵盖所有 DLT 活动，包括运营加密交易所、提供托管以及运营 NFT 市场。不过，GFSC 可能根据您的业务性质施加特定条件。该牌照不像 MiCA 那样按服务类别分级；相反，它是单一授权，采用基于原则的监管。

GFSC 制度的主要特点包括强制性的“DLT 授权框架”，要求企业证明其符合九项原则，包括风险管理、安全和消费者保护。GFSC 还要求提交“DLT 风险评估”和“DLT 商业计划”作为申请的一部分。

Consulting24 就监管预期为客户提供咨询，并帮助准备必要文件。我们不保证获批，但会基于我们在多个司法管辖区处理类似申请的经验提供专业指导。

直布罗陀加密牌照的资本要求

GFSC 未在法规中规定固定的最低资本要求。相反，它要求 DLT 提供商维持与其业务性质、规模和复杂程度相称的“充足财务资源”。这根据具体情况逐案评估。

在实践中，大多数申请人预计至少需要 100,000 至 200,000 欧元的资本，但对于交易量巨大或托管客户资产的平台，这一要求可能更高。资本必须以流动资产形式持有，并可能需要作为偿付能力缓冲予以维持。GFSC 还将考虑公司的预计收入、支出和风险敞口。

Consulting24 根据客户的商业计划，就适当的资本水平提供建议。我们将其与其他制度进行比较：例如，根据 MiCA，立陶宛要求交易所和托管服务具备 125,000 欧元资本，而巴拿马对标准公司没有最低资本要求。我们的团队帮助您构建资本结构，以满足 GFSC 的期望，同时避免不必要的过度资本化。

直布罗陀 NFT 市场的税务处理

直布罗陀为加密货币和 NFT 企业提供了有利的税收环境。主要特点包括：

  • 对出售加密资产或 NFT 所得利润不征收资本利得税。
  • 对加密货币交易不征收增值税（VAT），但中介服务可能适用增值税。
  • 企业所得税按利润的标准税率 12.5% 征收，但某些投资收入和资本利得可享受豁免。
  • 对支付给非居民的股息或利息不征收预提税。
  • 直布罗陀不属于欧盟增值税区，因此与欧盟客户的跨境交易可能具有不同的增值税影响。

需要注意的是，税务处理取决于您 NFT 市场的具体活动。例如，如果您的平台以法定货币收取费用，这些费用需缴纳企业所得税。如果您以加密货币赚取收入，则纳税事件发生在加密货币兑换为法定货币或用于支出之时。Consulting24 建议聘请当地税务顾问，以最优方式构建您的运营。我们可以与我们的直布罗陀税务专业人士网络进行协调。

直布罗陀加密货币牌照允许的活动

直布罗陀 DLT 牌照允许 NFT 市场开展以下活动：

  • 运营 NFT 上架、交易和拍卖平台。
  • 为 NFT 及相关加密资产提供托管或钱包服务。
  • 促进 NFT 与法定货币或其他加密资产（包括稳定币）的兑换。
  • 代表用户铸造 NFT（如果平台控制智能合约）。
  • 提供与 NFT 相关的质押或收益服务（如适用）。

未涵盖的活动包括：将 NFT 作为证券发行（这将属于证券法管辖范围）、提供投资建议，或运营衍生品交易所。如果某些活动构成高风险，GFSC 也可能对其进行限制。例如，允许匿名交易或 AML 控制薄弱的平台可能面临附加条件。

获得直布罗陀加密货币牌照的分步流程

直布罗陀 DLT 牌照的申请流程涉及多个阶段。Consulting24 与当地法律合作伙伴协调每一步。

  1. 初步咨询和业务评估：我们审查您的商业模式、目标市场和监管需求。我们确认直布罗陀是否合适，并提供成本估算。
  2. 公司注册：您必须注册一家直布罗陀公司（或已拥有一家）。这通常需要 1-2 周。
  3. 准备申请文件：包括详细的商业计划、AML/KYC 政策、DLT 风险评估、技术安全审计和财务预测。我们帮助起草这些文件。
  4. 提交给 GFSC：申请连同费用一并提交。GFSC 可能要求提供额外信息或澄清。
  5. GFSC 审查和面谈：监管机构进行彻底审查。关键人员（董事、受益所有人）可能会接受面谈。此阶段需要 3-6 个月。
  6. 批准和颁发牌照：如果获批，GFSC 将颁发附带任何具体条件的牌照。随后您必须遵守持续的报告和监管要求。
  7. 牌照后合规：年度审计、AML 更新以及向 GFSC 定期报告。Consulting24 可提供持续的合规支持。

与其他司法管辖区的申请流程相比，直布罗陀的流程更为密集，但提供了受尊重的监管地位。我们建议客户为从启动到拿到牌照预留 9-12 个月的时间。

直布罗陀 NFT 平台的银行和支付服务

获得银行服务是全球加密货币企业面临的关键挑战，直布罗陀也不例外。虽然直布罗陀拥有发达的金融业，但许多传统银行对接纳 DLT 提供商持谨慎态度。不过，也有一些专业银行和支付处理商为加密货币行业提供服务。

可选方案包括：

  • 直布罗陀本地银行，如 Gibraltar International Bank 及其他在严格 AML 合规下接受 DLT 客户的较小机构。
  • 来自 BCB Group 或 Clear Junction 等提供商的 EMI（电子货币机构）账户，可提供法定货币入金和出金通道。
  • 与您的 NFT 市场集成以处理法定货币交易的支付处理商。

Consulting24 可以为您引荐我们已审核过的银行合作伙伴。我们还会就构建支付流程以尽量减少摩擦提供建议。例如，使用多币种账户有助于管理 EUR、GBP 和 USD 结算。请注意，银行将要求对您的公司和受益所有人进行全面 KYC，并可能要求提供您的 GFSC 牌照副本或申请状态。

直布罗陀加密货币牌照对 NFT 市场的益处

为您的 NFT 市场牌照选择直布罗陀具有多项优势：

  • 监管信誉：GFSC 是受尊重的监管机构，直布罗陀牌照向合作伙伴、投资者和客户表明您的平台符合高标准。
  • 成熟的框架：DLT 制度自 2018 年起实施，提供了法律确定性和执法记录。
  • 税收效率：无资本利得税和较低的企业税率使直布罗陀对加密货币利润具有吸引力。
  • 欧洲时区和英国普通法：直布罗陀采用 CET 时区并遵循英国普通法，这为许多国际企业所熟悉。
  • 进入欧盟市场（脱欧后）：虽然直布罗陀不在欧盟内，但它与英国有特殊关系，并与欧盟 AML 标准保持一致，这可以促进跨境业务。

然而，直布罗陀并非最便宜或最快捷的选择。对于寻求更简单、低成本结构的创始人，巴拿马提供 6,000 欧元的统一公司设立费用，且无需加密货币特定牌照，尽管它缺乏同样的监管背书。Consulting24 帮助您根据业务目标权衡这些取舍。

合规与信任：持续义务

获得牌照后，您的 NFT 市场必须遵守持续的合规要求。这些包括：

  • 年度 AML/CFT 审计并向 GFSC 提交合规报告。
  • 始终维持充足的财务资源。
  • 报告业务的任何重大变化，包括新产品、关键人员或所有权变更。
  • 定期进行风险评估并相应更新政策。
  • 确保所有员工接受 AML 和数据保护培训。

GFSC 会进行定期检查，并可能要求提供临时信息。不合规可能导致罚款、暂停或吊销牌照。Consulting24 提供持续的合规支持，帮助您履行这些义务。我们还就 NFT 市场的最佳实践提供指导，例如对创作者和买家实施严格的 KYC，以及使用区块链分析工具监控可疑活动。

一般性指导，不构成法律意见。请务必就您的具体情况咨询合资格的律师。

申请直布罗陀加密牌照时的常见错误

根据我们为客户提供咨询的经验，以下是一些需要避免的常见陷阱：

  • AML 文件不充分：GFSC 期望看到针对您业务量身定制的详细、可操作的 AML 政策。通用模板不被接受。
  • 低估时间周期：许多申请人预期 3-4 个月，但流程往往需要 6-12 个月。请据此规划您的上线时间。
  • 缺乏本地实质：GFSC 期望公司在直布罗陀拥有真实存在，包括实体办公室、本地董事和合规官。不允许虚拟设置。
  • 资本不足：尽管没有固定的最低资本要求，但资本过少可能导致被拒。请准备至少覆盖 12 个月运营的切合实际的财务预测。
  • 忽视 NFT 特定风险：GFSC 可能会审查 NFT 市场的洗钱风险，例如洗售交易或匿名创作者。请在风险评估中处理这些问题。

Consulting24 通过提供结构化的申请路线图，帮助您避免这些错误。我们还会将直布罗陀流程与其他选项进行比较，例如瑞士的 FINMA 牌照或马耳他的 VFA 框架，这些选项可能有不同的要求。

常见问题

直布罗陀 DLT 牌照与 MiCA 牌照有什么区别？

直布罗陀的 DLT 牌照是独立制度，并非基于 MiCA。它采用原则导向监管，而 MiCA（自 2024 年起生效）在欧盟范围内提供统一框架。直布罗陀不属于欧盟，因此不提供护照通行权。不过，其制度成熟且在全球受到尊重。

我可以在直布罗陀无牌照运营 NFT 市场吗？

不可以。如果您的平台从直布罗陀提供 DLT 服务，例如 NFT 的交易、托管或兑换，您必须持有 DLT 牌照。无牌照运营可能导致罚款、刑事处罚和强制关闭。

直布罗陀加密牌照的有效期是多久？

该牌照无限期有效，但须进行年度续期和持续合规。GFSC 要求缴纳年费并提交报告。未能合规可能导致暂停或吊销。

直布罗陀 NFT 市场的主要 AML 要求有哪些？

您必须实施基于风险的 AML 计划，包括对所有用户进行客户尽职调查（CDD）、交易监控、可疑活动报告和记录保存。GFSC 期望针对 NFT 相关风险（如洗售交易和匿名创作者）制定具体政策。

直布罗陀对加密利润免税吗？

直布罗陀没有资本利得税，但对企业利润征收 12.5% 的企业所得税。加密对加密交易在转换为法币之前可能不会触发税务事件。不过，您应就您的具体活动寻求当地税务建议。

我可以使用直布罗陀公司为欧盟客户提供服务吗？

可以，但如果您面向欧盟客户，您必须遵守欧盟 AML 规则，并可能需要遵守 MiCA。直布罗陀不属于欧盟，因此如果您在欧盟有重要存在，可能需要在各个成员国注册或获得 MiCA 牌照。

如果我在获得牌照后改变业务模式会怎样？

任何重大变更都必须获得 GFSC 批准。这包括增加新服务、变更所有权或扩展到新的司法管辖区。未能通知可能导致处罚。

我可以远程申请直布罗陀牌照吗？

可以，申请可以远程准备，但 GFSC 期望公司在当地拥有实质（办公室、董事）。Consulting24 可以帮助您在当地安排这些事项。

直布罗陀牌照是否得到其他监管机构认可？

直布罗陀是英国海外领土，其监管机构是国际证券委员会组织（IOSCO）的成员。虽然不会自动获得认可，但直布罗陀牌照可以促进与其他司法管辖区银行和合作伙伴的关系。
