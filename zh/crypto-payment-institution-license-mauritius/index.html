什么是毛里求斯加密支付机构牌照？

加密支付机构牌照（也称为虚拟资产服务提供商牌照）是由毛里求斯金融服务委员会（FSC）颁发的监管批准。它允许公司根据 VAITOS 法提供数字资产托管、交易和支付处理等服务。该牌照旨在将加密活动纳入正规金融部门，确保符合反洗钱（AML）和反恐融资（CTF）标准。对于在毛里求斯境内或从毛里求斯经营加密支付业务的任何实体而言，这是强制性要求。

主要特点包括清晰的法律框架、有利的税收环境和简化的申请流程。该牌照有效期为一年，必须每年续期。FSC 维护着持牌 VASP 的公开登记册，这为您的客户增加了可信度和信任感。Consulting24 为整个流程提供咨询与协调服务，从公司设立到牌照提交，确保您的申请符合所有监管标准。

谁需要此牌照？

任何在毛里求斯境内或从毛里求斯向客户提供虚拟资产服务的企业都需要此牌照。典型申请人包括：

  • 为商户交易提供便利的加密支付处理商
  • 数字资产交易所（中心化和点对点）

  • ATM 和自助终端运营商

如果您的业务涉及为客户持有、转移或兑换加密货币，则属于 VAITOS 法的管辖范围。即使是服务毛里求斯客户的远程公司也可能需要注册。FSC 已发布指引，明确任何在毛里求斯设有营业地点或针对毛里求斯居民开展业务的实体都必须获得牌照。Consulting24 可以帮助您确定您的商业模式是否需要牌照，并指导您完成申请流程。

牌照类型与监管机构

监管机构是毛里求斯金融服务委员会（FSC），具体由其虚拟资产及首次代币发行服务（VAITOS）部门负责。牌照类型为第1类或第2类虚拟资产服务提供商（VASP）牌照，取决于所提供的服务。

第1类涵盖提供商持有客户资产的服务，如托管、交易和支付处理。这是支付机构最常见的牌照类型。第2类涵盖咨询及其他非托管服务，如投资组合管理或代币咨询。大多数支付机构需要第1类牌照，其涉及更严格的资本和合规要求。

FSC 根据适当人选标准、商业计划可行性、AML/CTF 政策和运营能力来评估申请。该监管机构以严谨但公正著称，典型处理时间为3-6个月。Consulting24 与当地合作伙伴协调，确保您的申请符合 FSC 标准，包括在需要时任命当地合规官。

资本要求

毛里求斯加密支付机构牌照的最低资本要求并未由法律明确规定，而是由 FSC 根据业务性质和规模确定。通常，FSC 期望第1类牌照的最低实缴资本为50,000至100,000欧元。对于第2类牌照，要求较低，通常在25,000欧元左右。

该资本必须始终维持，可以是法定货币或虚拟资产，但须遵守估值规则。资本作为抵御运营风险的缓冲，并证明财务实力。例如，如果您计划处理大额交易量，FSC 可能要求更高的资本金额。Consulting24 可以帮助您合理构建资本基础，并就您的商业模式所需的确切金额提供建议。我们还协助准备必要的财务预测，以支持您的资本充足性。

毛里求斯加密货币牌照是否获得国际认可？

毛里求斯是符合 FATF 标准的司法管辖区，其牌照获得许多国际合作伙伴和银行的认可。然而，认可取决于交易对手自身的尽职调查。该牌照增加了可信度，有助于建立银行关系和合作伙伴关系。

Class 1 和 Class 2 牌照有什么区别？

Class 1 牌照适用于提供商持有客户资产的托管服务（例如交易所、托管机构）。Class 2 牌照适用于非托管服务（例如咨询、投资组合管理）。大多数支付机构需要 Class 1 牌照，其资本和合规要求更高。
