什么是百慕大加密 OTC 交易台牌照？

百慕大加密 OTC 交易台牌照允许公司运营数字资产场外交易平台。OTC 交易台促进机构客户之间的大额交易，避免公开交易所的流动性和滑点问题。该牌照由百慕大金融管理局（BMA）依据《2018 年数字资产业务法》（DABA）颁发。其涵盖代表客户进行数字资产交易、经纪和托管等活动。

百慕大的监管制度以其严格标准著称，包括反洗钱（AML）和反恐融资（CTF）要求。该司法管辖区尤其吸引寻求声誉良好、监管完善且拥有明确数字资产法律框架的环境的公司。截至 2026 年，百慕大仍是面向北美和欧洲机构客户的 OTC 交易台的首选之地。

该牌照并非简单的注册；它涉及严格的申请流程，审查您的商业计划、治理和财务状况。BMA 期望申请人展现对数字资产风险的深刻理解，包括市场波动、网络安全和运营韧性。例如，为养老基金处理比特币互换的 OTC 交易台需要展示其如何管理交易对手风险和结算终局性。

谁需要百慕大加密 OTC 交易台牌照？

任何在百慕大境内或从百慕大向客户提供数字资产 OTC 交易服务的公司都必须持有牌照。这包括：

  • 代表机构投资者执行大额交易的 OTC 经纪商。
  • 为数字资产提供流动性的做市商。
  • 提供撮合自营交易或代理执行的平台。
  • 将 OTC 交易与托管或咨询服务相结合的公司。

如果您的商业模式涉及为收取费用或价差而促成双方之间的交易，您很可能属于 BMA 对数字资产业务的定义范围。有限活动存在豁免情形，但大多数商业 OTC 交易台需要完整牌照。Consulting24 可以帮助确定适合您运营的正确牌照类别。

例如，仅提供买卖双方撮合公告板而不处理资金的初创企业可能不需要牌照，但一旦您进行托管或执行交易，牌照便成为强制要求。BMA 还会考虑您的客户是否位于百慕大，即使您的公司在其他地方注册成立。如果您在百慕大设有实体存在，则必须申请。

牌照类型与监管机构

百慕大金融管理局（BMA）是百慕大数字资产业务的唯一监管机构。相关牌照为 F 类（完整）数字资产业务牌照，允许包括 OTC 交易、托管和交易所运营在内的所有活动。此外还有面向活动有限的较小公司的 M 类（修改）牌照，但大多数 OTC 交易台将需要 F 类牌照。

BMA 的监管框架以原则为基础，侧重于风险管理、资本充足性和客户保护。申请流程包括对商业计划、治理结构、AML/CTF 政策和财务预测的详细审查。BMA 还会对董事和高级管理层进行适当人选审查。

F 类是最全面的牌照，允许您运营 OTC 交易台、托管客户资产，甚至发行代币。如果您只想在不托管的情况下进行交易经纪，M 类可能足够，但 BMA 鼓励为提升信誉而申请完整牌照。Consulting24 建议大多数 OTC 交易台申请 F 类牌照，以避免未来的限制。

资本要求

BMA 要求 F 类牌照的最低资本至少为 100,000 USD。该资本必须始终维持，可以是现金或流动资产形式。根据交易量或风险状况，可能需要更高的资本。资本要求旨在确保公司拥有充足的财务资源来覆盖运营风险和客户义务。

除资本外，BMA 可能根据活动要求提供保证债券或职业赔偿保险。Consulting24 就构建资本以满足 BMA 期望同时优化运营效率向客户提供建议。例如，如果您计划进行大额交易，BMA 可能要求 200,000 USD 或更多。资本必须存放在百慕大或 BMA 批准的司法管辖区的银行账户中。

税务处理

百慕大不征收企业所得税、资本利得税或预提税。其税收制度基于工资税和社会保险缴款。对于数字资产业务而言，这意味着场外交易（OTC）的利润无需缴纳企业所得税。但是，如果公司有雇员，则必须进行工资税登记。某些文件还需缴纳印花税，但通常不适用于交易活动。

百慕大的税收中性环境是加密OTC交易台的一大优势，因为它允许公司保留更多的交易利润。Consulting24建议咨询税务顾问，以了解对您业务结构的具体影响。例如，如果您在百慕大有雇员，您需要就超过起征点的薪资缴纳约4.75%的工资税。数字资产服务不适用增值税或销售税。

允许的活动

F类牌照允许开展以下活动：

  • 运营数字资产OTC交易台。
  • 在买卖双方之间进行交易经纪。
  • 提供数字资产托管服务。
  • 发行和赎回稳定币或其他数字代币。
  • 担任做市商。
  • 提供与数字资产相关的咨询服务。

BMA不允许在未获得额外许可的情况下提供无牌照的零售交易服务。OTC交易台也可以从事自营交易，但须遵守资本充足率规则。所有活动必须遵守AML/CTF法规以及BMA的业务行为规则。例如，如果您想向机构客户提供保证金交易，您必须披露风险并维持额外的资本。

分步申请流程

百慕大加密OTC交易台牌照的申请流程包括几个阶段：

  1. 申请前咨询：与Consulting24讨论您的业务模式，以确定合适的牌照类别和结构。
  2. 文件准备：准备详细的商业计划、财务预测、AML/CTF政策、治理框架以及董事的个人问卷。
  3. 提交：将申请连同申请费一并提交给BMA。
  4. BMA审查：BMA进行彻底审查，可能包括要求提供额外信息或澄清。
  5. 面谈：BMA可能会对关键人员进行面谈，以评估其适当性和 suitability。
  6. 批准：一旦满意，BMA将颁发牌照，但可能附带任何条件。
  7. 牌照后：实施持续的合规报告并维持所需的资本。

银行与支付

由于被认为存在风险，在百慕大为加密OTC交易台开设银行账户可能具有挑战性。但是，百慕大有许多银行对数字资产业务持开放态度，前提是该公司持有BMA牌照。银行通常要求最低存款、牌照证明以及详细的商业计划。

Consulting24可以将客户介绍给百慕大及其他司法管辖区的银行合作伙伴。对于支付处理，公司可能需要使用支持加密与法币兑换的第三方支付提供商。BMA期望公司拥有强大的支付控制措施以防止洗钱。例如，您可以使用像Butterfield或HSBC Bermuda这样的银行，它们设有专门服务持牌数字资产公司的团队。它们通常要求最低存款50,000 USD以及董事的个人担保。

百慕大为OTC交易台提供了多项优势：

合规与信任

合规是百慕大监管框架的核心。持牌人必须实施强有力的AML/CTF计划，进行定期审计，并向金融情报局报告可疑交易。BMA还要求提交年度财务报表和合规报告。

为维护信任，公司应聘请合格合规官并考虑外部审计。Consulting24提供持续的合规支持，包括政策更新和培训。这是一般性指导，并非法律建议；请务必就您的具体情况咨询法律专业人士。例如，您必须每六个月提交一份合规报告，详细说明交易量、客户尽职调查以及任何可疑活动。BMA可能每两年进行一次现场检查。

申请流程中的常见错误

申请人常犯以下错误：

  • 治理不善：董事必须具备相关经验并通过适当性测试。
  • 低估资本：确保您拥有足够的流动资本以满足100,000 USD的最低要求及运营需求。

BMA 要求 Class F 牌照的最低资本为 100,000 USD。该资本必须以流动资产形式维持。根据交易量或风险状况，可能要求更高的金额。

百慕大 OTC 交易台牌照有哪些税收优惠？

我可以在没有牌照的情况下在百慕大运营 OTC 交易台吗？

不可以。任何在百慕大境内或从百慕大提供数字资产 OTC 交易服务的公司都必须持有 BMA 颁发的牌照。无牌经营属于违法行为，将受到处罚。

Class F 牌照允许开展哪些活动？

Class F 牌照允许开展 OTC 交易、经纪、托管、代币发行、做市和咨询服务。这是数字资产业务中最全面的牌照。

百慕大牌照的持续合规成本是多少？
