什么是泰国加密 NFT 市场牌照？

泰国加密 NFT 市场牌照是泰国证券交易委员会（SEC）根据《数字资产业务法令》（B.E. 2561，2018 年）颁发的监管授权。该牌照允许运营者在中心化平台上促进数字资产（包括加密货币和非同质化代币 NFT）的交易。任何提供与数字资产相关的交易所、经纪、交易商或基金管理服务的业务均需持有该牌照。

泰国 SEC 将数字资产业务分为四类：交易所、经纪商、交易商和基金管理人。对于 NFT 市场而言，最相关的类别是数字资产交易所牌照，该牌照允许撮合 NFT 及其他代币的买卖双方。该监管框架旨在保护投资者、防止市场滥用并确保运营完整性。截至 2026 年，SEC 已更新针对 NFT 的专项指南，包括代币分类要求和反洗钱（AML）措施。

该牌照的主要特点包括：必须加入数字资产运营商协会、遵守 SEC 通知规则以及定期报告。牌照有效期为一年，须每年续期。Consulting24 提供全流程咨询与协调服务，从准备申请材料到与 SEC 沟通对接。

谁需要泰国加密 NFT 市场牌照？

任何计划在泰国运营允许用户买卖或交易 NFT 及加密货币的平台实体，都必须获得 SEC 颁发的牌照。这包括：

  • 上架并促进 NFT 二级交易的中心化 NFT 市场
  • 同时支持 NFT 的加密货币交易所
  • 撮合数字资产买卖双方的经纪平台
  • 以自有账户交易数字资产的交易商
  • 提供数字资产投资计划的基金管理人

面向泰国用户的外国公司同样须遵守相关规定。SEC 要求在泰国注册成立公司并设有注册办公地址。即使您的平台设在海外，只要面向泰国居民推广或接受泰铢，您很可能需要牌照。Consulting24 为外国实体提供公司设立和牌照申请的咨询与协调服务。如需更快捷的替代方案，可考虑巴拿马牌照，其无本地注册要求，固定费用为 EUR 6,000。

牌照类型与监管机构

泰国数字资产业务的主要监管机构是泰国证券交易委员会（SEC）。SEC 在财政部领导下运作，负责执行《数字资产业务法令》。NFT 市场的牌照类型通常为数字资产交易所牌照，允许运营者促进数字资产交易。此外还有经纪商、交易商和基金管理人牌照，但交易所牌照对市场平台最为常见。

SEC 已发布涵盖资本要求、资产托管、技术标准和 AML/CFT 义务的详细法规。截至 2026 年，SEC 要求交易所的最低注册资本为 THB 50 million（约 EUR 1.3 million），并维持不低于总负债 7% 的净资本比率。监管机构还要求至少一名董事和一名经理常驻泰国。

对于 NFT 相关活动，如果 NFT 具有实用功能或投资属性，SEC 将其归类为数字资产。纯收藏品或艺术类 NFT 可能获得豁免，但如果您的市场涉及份额化或交易，则需持有牌照。Consulting24 与 SEC 沟通协调，为您的业务模式确定准确分类。

资本要求

泰国数字资产交易所的最低注册资本为 THB 50 million（约 EUR 1.3 million）。该资本须在申请时全额实缴。SEC 还要求公司维持不低于总负债 7% 的净资本比率，即公司须拥有充足的流动资产以覆盖其债务。

对于其他许可证类型（经纪商、交易商、基金管理人），资本要求较低：经纪商和交易商为 2500 万泰铢，基金管理人为 1000 万泰铢。然而，对于作为交易所运营的 NFT 市场，适用 5000 万泰铢的门槛。资本必须存放在泰国银行账户中，未经 SEC 批准不得用于运营支出。

Consulting24 提供建议并协调资本结构安排以确保合规。如果资本要求构成障碍，可考虑门槛较低的司法管辖区，例如立陶宛（CASP 为 125,000 欧元）或巴拿马（无最低资本要求）。

泰国加密 NFT 市场的税务处理

泰国对数字资产有专门的税收制度。截至 2026 年，税务局将数字资产交易利润作为资本利得征税，个人适用个人所得税税率（最高 35%），公司适用 20% 的企业所得税税率。对于 NFT 市场，平台从交易手续费中获得的收入需缴纳企业所得税，以及服务费 7% 的增值税（VAT）。

此外，SEC 要求交易所对向外国实体支付的服务款项代扣 15% 的预提税。对于 NFT 创作者，一级销售所得可能作为普通收入征税，而二级销售可能涉及资本利得税。NFT 的税务处理仍在演变中，SEC 和税务局已发布联合指引。Consulting24 提供建议并与当地专家协调税务规划，以确保合规并优化税务负担。

与其他司法管辖区相比，巴拿马实行属地税制，仅对本地来源收入征税，且对数字服务不征收增值税。请浏览我们的巴拿马页面了解详情。

泰国加密 NFT 市场许可证允许的活动

持有 SEC 颁发的数字资产交易所许可证，您的 NFT 市场可以开展以下活动：

  • 在中心化订单簿上促成加密货币和 NFT 的交易
  • 提供数字资产托管服务（需经 SEC 批准）
  • 提供质押或借贷服务（受额外法规约束）
  • 上架被归类为数字资产（非证券）的 NFT
  • 以法币或加密货币收取交易手续费
  • 通过合作银行整合泰铢入金通道

未经额外许可证不允许的活动包括：提供衍生品或保证金交易、发行稳定币，或作为支付系统运营。SEC 还禁止交易代表证券或被视为非法的 NFT。Consulting24 提供建议并协调活动范围以确保合规。如需更广泛的范围，可考虑迪拜 VARA 许可证，其允许更广泛的活动。

获取许可证的分步流程

银行与支付整合

在泰国运营 NFT 市场需要与本地银行系统整合，以实现法币入金和出金。泰国银行对与加密业务合作通常持谨慎态度，但持牌交易所可以开设企业账户。泰国央行已发布指引，允许银行为数字资产运营商提供服务，前提是进行强化尽职调查。

常见的支付方式包括银行转账、PromptPay，以及通过第三方处理商的信用卡/借记卡。对于加密货币与法币的兑换，交易所通常与持牌的加密-法币网关合作。SEC 要求客户法币资金存放在泰国银行的隔离账户中。

常见问题

在泰国办理加密 NFT 市场牌照的费用是多少？

总费用包括 THB 100,000 申请费、THB 200,000 年费，以及从 EUR 15,000 起的法律/咨询费用。您还需要为公司实缴 THB 50 million 的资本。具体费用取决于您的业务模式。

获得泰国加密牌照需要多长时间？

从申请到发牌通常需要 6 到 12 个月。这包括公司注册、文件准备、SEC 审核以及批准后的步骤。Consulting24 提供咨询与协调以加快流程。

申请是否需要在泰国注册公司？

是的，SEC 要求申请人是在泰国注册成立、并在泰国设有注册办事处的公司。该公司必须至少有一名泰国董事，并满足资本要求。

在泰国，我可以在没有牌照的情况下运营 NFT 市场吗？

不可以，根据《数字资产业务法令》，无牌照运营数字资产交易所属于违法行为。处罚包括罚款和监禁。在启动之前必须获得牌照。

泰国加密交易所的最低资本是多少？

最低注册资本为 THB 50 million（约 EUR 1.3 million），须全额实缴。对于经纪商或交易商，要求为 THB 25 million。

根据泰国法律，NFT 是否受到不同对待？

是的，SEC 会根据 NFT 的特性进行分类。实用型 NFT 可能获得豁免，但如果它们代表投资或在市场上交易，则被视为数字资产，需要牌照。

泰国的 NFT 市场收入适用哪些税种？

净利润适用 20% 的企业所得税，服务费适用 7% 的 VAT。向境外实体付款可能适用 15% 的预提税。具体事宜请咨询税务顾问。

我可以用巴拿马牌照代替泰国牌照吗？

可以，巴拿马提供 EUR 6,000 一口价的金融科技牌照，无资本要求，办理周期为 4-6 周。对于面向全球用户的 NFT 市场而言，这是一个热门替代方案。
