什么是马耳他加密货币 OTC 柜台牌照？

马耳他加密货币 OTC 柜台牌照是 MFSA 依据 VFAA 颁发的监管授权。它允许公司运营虚拟金融资产的场外（OTC）交易柜台，直接撮合买卖双方而无需使用公开交易所。该牌照涵盖订单执行、自营交易以及提供与加密资产相关的投资建议等活动。

与通过订单簿服务多个交易对手的交易所牌照不同，OTC 柜台牌照专注于与机构客户进行大额交易，提供隐私性和价格确定性。马耳他的 VFA 框架与欧盟《加密资产市场法规》（MiCA）保持一致，确保持牌公司可在欧洲经济区范围内通行提供服务。MiCA 自 2025 年起全面生效，按服务类别设定 EUR 50,000、125,000 和 150,000 的资本档次，而马耳他的 Class 3 与自营交易的 EUR 125,000 档次相对应。

该牌照的主要特点包括遵守反洗钱（AML）规则、客户资产隔离以及向 MFSA 持续报告。对于任何希望在马耳他境内或从马耳他运营合规 OTC 柜台的公司而言，该牌照必不可少。如需更具成本效益、采用固定费用的替代方案，请参阅我们的巴拿马方案。

谁需要马耳他加密货币 OTC 柜台牌照？

任何以自营或代理方式促成交易对手之间直接交换加密资产业务的企业，都需要该牌照。典型申请人包括：

  • 服务对冲基金、家族办公室及高净值人士的机构 OTC 柜台。
  • 以自有账户交易加密资产的自营交易公司。
  • 在交易所之外撮合买卖双方的经纪商。
  • 将 OTC 交易整合到其平台中的金融科技公司。

如果您的公司处理大额大宗交易、提供流动性或在公开交易所之外提供价格协商，马耳他加密货币 OTC 柜台牌照就是合适的监管工具。由于 MiCA 的属地适用范围，即使公司位于马耳他境外，只要面向欧盟客户，也可能需要该牌照。例如，一家服务欧盟机构投资者的英国 OTC 柜台，必须持有来自马耳他等欧盟成员国的 MiCA 合规牌照。

牌照类型与监管机构

监管机构是马耳他金融服务管理局（MFSA）。根据 VFAA，VFA 牌照分为四类。对于 OTC 柜台业务，相关类别为 Class 3，其允许：

  • 代客户执行订单。
  • 自营交易。
  • 投资组合管理。
  • 投资建议。
  • 订单的接收与传递。

Class 3 是交易活动最全面的牌照。它要求最低资本 EUR 125,000，且必须始终维持该资本。MFSA 会对董事和股东进行全面的适当人选测试，并要求具备本地存在，包括实体办公室和至少一名常驻董事。监管机构还会评估公司的商业计划、风险管理框架和 AML 管控措施。与爱沙尼亚加密货币牌照相比，马耳他的要求更为严格，但提供欧盟通行权。

资本要求

对于 Class 3 VFA 牌照（OTC 柜台），最低资本要求为 EUR 125,000。该资本必须全额缴足并以流动性形式持有，如现金或现金等价物。MFSA 可能根据公司的风险状况、交易量和运营支出要求更高的金额。资本必须在整个牌照期内维持，并接受持续监控。

相比之下，较低类别（Class 1 和 Class 2）的资本要求较低，但不允许自营交易。Class 4（交易所）要求 EUR 730,000。EUR 125,000 的门槛专为既执行客户订单又以自身名义交易的 OTC 柜台而设。根据 MiCA，自营交易的欧盟全境最低要求为 EUR 125,000，因此马耳他的要求与之保持一致。如需资本要求较轻的替代方案，可考虑巴拿马，其加密货币牌照无最低资本要求。

税务处理

马耳他为持牌加密货币公司提供了极具竞争力的税收制度。标准企业所得税税率为 35%，但通过马耳他的完全归集抵免制度和退税机制，实际税率可低至 5%。这是通过对已分配利润所缴税款给予 6/7 的退税实现的（某些类型的收入为 5/7）。

此外，马耳他对支付给非居民的股息不征收预提税，对交易利润不征收资本利得税（仅对某些资产的已实现收益征税），并拥有广泛的双重征税协定网络。加密货币交易服务的增值税通常予以免征。这一税收结构使马耳他对寻求优化全球税负的 OTC 柜台运营商颇具吸引力。例如，一家利润为 EUR 1 million 的公司，在退税后实际缴纳税款可能低至 EUR 50,000。

允许的活动

持有 Class 3 VFA 牌照，加密货币 OTC 柜台可从事以下活动：

  • 为客户执行订单（在场外撮合买卖订单）。
  • 自营交易（以自有账户进行交易）。
  • 加密货币资产的投资组合管理。
  • 就 VFA 提供投资建议。
  • 订单的接收与传递。
  • 客户资产的安全托管（如作为交易的附属服务）。

不允许的活动包括运营多边交易设施（交易所）或发行 VFA。该牌照严格用于 OTC 和经纪服务。所有活动都必须遵守 AML/CFT 义务和 MFSA 的业务行为规则。若从事交易所业务，则需要 Class 4 牌照，其资本门槛更高，为 EUR 730,000。

常见问题

马耳他加密货币 OTC 柜台牌照的最低资本是多少？

Class 3 VFA 牌照（OTC 柜台）的最低资本要求为 EUR 125,000。该资本必须全额缴足并以流动形式持有。MFSA 可能根据风险状况要求更高的金额。

获得马耳他加密货币 OTC 柜台牌照需要多长时间？

MFSA 通常需要 6-12 个月从提交到作出决定。申请前准备可能需要 2-4 个月。总时间通常为 8-16 个月。

我可以将马耳他牌照通行证到其他欧盟国家吗？

可以，根据 MiCA，马耳他 VFA 牌照允许您在无需额外授权的情况下在整个 EEA 提供服务。这是马耳他牌照的一项关键优势。

马耳他持牌加密公司的实际税率是多少？

通过马耳他的退税制度，实际税率可低至 5%。标准税率为 35%，但股东可就已分配利润申请 6/7 的退税。

我需要在马耳他有实体办公室吗？

是的，MFSA 要求在马耳他设有实体办公室并配备本地员工，包括至少一名常驻董事。这是实质要求的一部分。

Class 3 牌照下不允许开展哪些活动？

不允许运营多边交易设施（交易所）或发行虚拟金融资产。如需开展交易所业务，则需要 Class 4 牌照，资本要求为 EUR 730,000。

对于 OTC 柜台牌照，马耳他与巴拿马相比如何？

巴拿马提供 EUR 6,000 的固定牌照费用，无资本要求，0% 税率，办理周期为 4-6 周。但它不提供欧盟通行证。马耳他更适合进入欧盟市场。

获得牌照后有哪些持续的合规义务？

持续义务包括年度经审计财务报表、AML/CFT 监控、维持资本、任命合规官和 MLRO，以及定期向 MFSA 报告。
