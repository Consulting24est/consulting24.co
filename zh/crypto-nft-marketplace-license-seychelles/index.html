什么是塞舌尔加密 NFT 市场牌照？

塞舌尔加密 NFT 市场牌照是金融服务管理局（FSA）根据《2007 年证券法》和《金融服务管理局法》颁发的监管授权。它允许企业运营一个平台，供用户使用加密货币购买、出售和交易非同质化代币（NFT）。该牌照涵盖 NFT 的初级发行（如数字艺术发售）和二级市场交易。

与某些司法管辖区要求每项活动分别取得牌照不同，塞舌尔为数字资产服务（包括 NFT 市场运营）提供统一牌照。该框架设计灵活，但仍要求严格的 AML/KYC 程序、资本储备和定期报告。截至 2026 年，FSA 已更新其指引以符合 FATF 建议，确保国际公信力。

谁需要此牌照？

任何在塞舌尔境内或从塞舌尔开展使用加密货币进行 NFT 交易业务的企业都必须取得此牌照。典型申请人包括：

  • NFT 市场（初级销售和二级交易）
  • NFT 发行平台和铸造平台
  • 碎片化 NFT 平台

牌照类型与监管机构

监管机构：金融服务管理局（FSA）

FSA 是塞舌尔数字资产服务的唯一监管机构。它根据《证券法》为 NFT 市场颁发单一类型的牌照。该牌照称为“数字资产服务提供商牌照”（DASP），涵盖与数字资产（包括 NFT）相关的所有活动。没有单独的 NFT 专属牌照；DASP 牌照的范围足够广泛，可涵盖 NFT 运营。

FSA 要求持牌人在塞舌尔保持实体存在，包括注册办事处和本地董事或代表。监管机构还要求年度审计、AML 合规和定期报告。Consulting24 与本地代理协调，代表您满足这些要求。如需了解申请流程的更多信息，请参阅我们的申请流程页面。

资本要求

FSA 未对 NFT 市场牌照规定固定的最低资本。相反，资本要求根据您业务的风险状况和交易量逐案确定。在实践中，大多数申请人被要求维持 50,000 欧元至 100,000 欧元的最低实缴资本。该资本必须存入塞舌尔银行账户，并可用于运营支出。

税务处理

塞舌尔为 NFT 市场运营商提供极为优惠的税收制度。主要优势包括：

  • 企业所得税：与塞舌尔居民无业务往来的国际商业公司（IBC）为 0%。
  • NFT 销售利润无需缴纳资本利得税。
  • 向非居民支付的股息或利息无需缴纳预提税。
  • 向海外客户提供的数字服务无需缴纳增值税。

但是，如果您的NFT市场服务于塞舌尔居民，则可能适用15%的标准企业所得税税率。大多数离岸NFT平台都注册为IBC，以享受0%的税率。Consulting24可以帮助您设计公司架构，在保持合规的同时实现税务效率最大化。如需与其他税收制度进行比较，请参阅我们的司法管辖区页面。

分步申请流程

  1. 公司注册：注册塞舌尔国际商业公司（IBC），并设有注册办事处和本地董事。
  2. 文件准备：准备商业计划书、AML/KYC政策、风险评估、财务预测和组织架构。
  3. 资本存入：开立塞舌尔银行账户并存入所需资本。
  4. 提交申请：向FSA提交许可证申请，包括所有支持文件和申请费。
  5. 监管审查：FSA审查申请，可能需要2至4个月。他们可能会要求提供额外信息或澄清。
  6. 许可证签发：获批后，许可证即签发。此后您必须遵守持续报告和审计要求。

应避免的常见错误

创始人在申请塞舌尔NFT市场许可证时，常会犯一些本可避免的错误：

常见问题

FSA并未设定固定的最低资本。相反，它基于风险来评估资本。大多数申请人被要求维持50,000欧元至100,000欧元的实缴资本。Consulting24可以就适合您业务的金额提供建议。

塞舌尔NFT市场牌照允许开展哪些活动？

该牌照涵盖运营NFT市场、首次发行（铸造）、托管钱包服务、份额化、点对点转让以及法币兑加密货币入金通道。它不涵盖银行业务、证券发行（除非NFT被认定为证券），或未经单独许可的投资建议。

我需要在塞舌尔有一名本地董事吗？

是的，FSA要求有一名塞舌尔居民担任本地董事或代表。Consulting24可以安排名义董事服务来满足这一要求，同时您保留对业务的控制权。

持续合规义务有哪些？

持牌人必须进行年度AML审计，向FSA提交财务报表，维持本地注册办事处和董事，向FIU报告可疑交易，并在活动发生变化时更新商业计划。不合规可能导致罚款或吊销牌照。

我可以凭塞舌尔牌照为欧盟客户提供服务吗？

塞舌尔牌照不提供欧盟通行权。要直接为欧盟客户提供服务，您可能需要根据MiCA获得某个欧盟成员国的牌照。不过，您可以从塞舌尔运营并服务非欧盟市场。Consulting24可以帮助您评估最适合您目标市场的司法管辖区。

塞舌尔对NFT市场是否免税？

不与塞舌尔居民开展业务的国际商业公司（IBC）享受0%企业所得税、无资本利得税，以及股息无预提税。如果您为塞舌尔居民提供服务，则适用标准15%的企业所得税。大多数离岸NFT平台以IBC形式构建，以实现税务效率。

申请需要哪些文件？
