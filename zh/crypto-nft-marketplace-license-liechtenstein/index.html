什么是列支敦士登加密 NFT 市场牌照？

列支敦士登加密 NFT 市场牌照是依据 TVTG（代币及可信技术服务提供商法）颁发的监管授权。它允许公司运营一个平台，供用户创建、购买、出售和交易非同质化代币（NFT）及其他数字资产。该牌照是列支敦士登全面区块链监管的一部分，涵盖所有类型的代币化服务，包括交易、托管和转移。

与某些将 NFT 视为不受监管收藏品的司法管辖区不同，列支敦士登明确将 NFT 纳入其法律框架，为市场运营者提供了清晰指引。该牌照由列支敦士登金融市场管理局（FMA）颁发，负责监督反洗钱（AML）和投资者保护规则的合规情况。这使列支敦士登成为欧洲对 NFT 企业而言最负盛名、最具前瞻性的司法管辖区之一。TVTG 于 2020 年颁布，此后经过更新，已涵盖新兴代币类型，包括 NFT、证券型代币和实用型代币。

谁需要此牌照？

任何在列支敦士登境内或从列支敦士登运营促进 NFT 或其他代币化资产交易平台的公司，均需依据 TVTG 获得牌照。这包括：

  • 用户可上架并出售数字艺术、收藏品、音乐或虚拟房地产的 NFT 市场。
  • 提供 NFT 一级发行（铸造）和二级交易的平台。
  • 代表客户为 NFT 提供托管或转移服务的企业。
  • 接受加密货币或法定货币作为 NFT 支付方式的市场。

如果您的商业模式涉及上述任何活动，您必须从 FMA 获得牌照。即使您的公司注册在列支敦士登境外，如果您面向列支敦士登居民或在 EEA 提供服务，也可能需要牌照。Consulting24 可以评估您的具体情况并就牌照的必要性提供建议。例如，为欧洲收藏家铸造 NFT 艺术品的初创企业很可能需要牌照，而纯粹的信息平台若不涉及交易则可能不需要。

牌照类型与监管机构

列支敦士登 NFT 市场运营者的相关牌照是 TVTG 下的代币服务提供商牌照。监管机构是列支敦士登金融市场管理局（FMA），负责监督所有金融服务，包括加密资产服务。FMA 以其务实的作风和全面而公正的审查流程而闻名。

根据 TVTG，服务提供商分为若干子类别，包括代币发行人、代币托管人和代币转移服务提供商。NFT 市场通常需要这些授权的组合，具体取决于平台是持有客户资产还是仅促进点对点交易。Consulting24 帮助根据您的商业模式确定牌照的确切范围。FMA 还要求至少一名董事或管理人员为列支敦士登或 EEA 居民，这可以通过我们的网络进行安排。

主要文件包括详细的商业计划书、AML/CTF 政策、风险评估、组织架构图、财务预测以及资本证明。所有文件必须使用德语或英语。Consulting24 可为您准备这些文件。

我可以在列支敦士登无牌照经营 NFT 市场吗？

持续合规要求有哪些？
